# MarkFlow Core

Shared contexts, document state, geometry, XML support, rendering and lifecycle for the independent MarkFlow extensions. Use the individual feature packages listed in the [extension catalog](../../docs/extensions.md). Share one `GuidesState` and one options object when combining rulers and guides. Shared modules preserve class identity, bridge registration and coordination between extensions.

This support package has no Angular or application-specific backend dependency. No license has been granted yet.
